# Contributing

Thanks for considering a contribution to Photo Agents.

## Getting started

1. Fork the repo and clone your fork.
2. `pip install -e ".[all]"` to install every optional client/integration.
3. Copy `photoagents/config/keys_template.py` to `credentials.py` and fill in a provider key.

## Making changes

- Keep pull requests focused on a single change where possible.
- Follow the existing code style in the file you're editing.
- Add or update tests under `tests/` when you change behavior.

## Reporting bugs

Open an issue using the bug report template and include steps to reproduce.
